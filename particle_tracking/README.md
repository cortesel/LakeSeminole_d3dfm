This folder contains the Jupyter Notebook scripts to run the dorado model using the Delft3D-FM model output. There are 2 scripts:
- run_d3dfm_dorado_multiple_points.ipynb: this script allows to select multiple injections points and drop any number of particles in each point. Particles are dropped ONE time and AT THE SAME time.
- run_d3dfm_dorado_staggered_drops.ipynb; this script allows to select multiple injection points and drop a number of particles at multiple times at a specific frequency.

There is also a folder showing an example of the outputs.
